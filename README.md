Gunakan Node.js 22.12+ dan npm. Jalankan npm install lalu npm start untuk pengembangan.
Jalankan npm run build dan npm run preview untuk memeriksa versi produksi.
Folder dist berisi versi siap diunggah ke hosting statis. Untuk melihatnya tanpa memasang npm, jalankan python -m http.server 8080 di dalam dist dan buka http://localhost:8080.
Formulir kontak membuka draf WhatsApp yang dapat ditinjau dan dikirim pengunjung.
